# 订阅分组每日不可用时段

在管理后台的「分组管理」中创建或编辑订阅类型分组，开启「每日不可用时段」，填写开始和结束时间，然后保存。

例如夜间卡只允许每日 22:00 至次日 08:00 使用，可设置：

- 不可用开始：`08:00`
- 不可用结束：`22:00`

如果需要每天夜间禁用，则设置 `22:00` 至 `08:00`，系统会自动按跨午夜时段处理。

规则：

- 按系统配置的时区每日重复执行，页面显示系统时区。
- 包含开始时间，不包含结束时间；开始和结束时间不能相同。
- 每个订阅分组支持一个每日不可用时段，关闭开关即可恢复全天可用。
- 不可用时段内，网关拒绝该分组的新请求，返回 HTTP 403。密钥绑定多个分组时，会跳过当前不可用的分组继续选择。
- 时段限制不会暂停订阅有效期，也不会改变原有额度和高峰倍率规则。
- 套餐购买页、已有订阅和密钥分组信息会展示每日不可用时段。

管理员创建和更新分组接口接受以下字段；更新时省略字段会保留原值：

```json
{
  "subscription_type": "subscription",
  "unavailable_time_enabled": true,
  "unavailable_start": "08:00",
  "unavailable_end": "22:00"
}
```

时间格式为 `HH:MM`（`00:00` 至 `23:59`）。切换为普通类型分组时，系统会清空不可用时段配置。
